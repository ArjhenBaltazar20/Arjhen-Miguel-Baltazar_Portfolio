## Run it locally

Requires [Node.js](https://nodejs.org/) 22 or newer.

```bash
npm install
npm run dev
```

Then open **http://localhost:8443**.

On Windows PowerShell, use `npm.cmd` in place of `npm` if script execution is disabled.

To create a production build in `dist/`:

```bash
npm run build
```
